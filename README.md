Automatic Smart Billing Cart Using RFID

Overview

An Arduino-based smart billing cart that uses RFID technology for product identification and billing.

Components Used

- Arduino Nano
- EM-18 RFID Reader (125 kHz)
- RFID Tags
- 16×2 LCD Display
- Red and Green LEDs
- Push Buttons
- Regulated 5V Power Supply

Working Principle

- RFID reader scans the product tag.
- Arduino processes the scanned information.
- LCD displays product and billing details.
- Green LED indicates a successful scan.
- Red LED indicates item deletion.

Technologies Used

Arduino, Embedded C/C++, RFID and LCD Interfacing.
